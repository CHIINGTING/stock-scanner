## 拆分原則

這件事被拆成兩半，拆法本身是結論的前提：

| | 性質 | 處置 |
|---|---|---|
| 「0.00% 被標成**價跌**」 | **假陳述** —— 不是判斷 | **直接修** |
| 「−0.26% 算不算跌」 | **判斷** —— 線畫在哪 | **先驗證，未migrate** |
| 「平盤該值幾分」 | **策略語意** | **先驗證，未migrate** |

`priceUp := closes[n-1] > closes[n-2]` 是嚴格大於，平盤落入 else 分支。實際掃描中
**123 檔有 13 檔（10.6%）今日平盤**，全部被標成「價跌量縮」。

## 已修正（資料正確性）

`internal/scanner/scorer.go`：

```go
priceFlat := closes[n-1] == closes[n-2]   // 恰好相等，不是 ±0.5% 帶
```

- 新標籤 **平盤量增 / 平盤量縮**
- `pvCSS` 給它們**自己的中性色**。少了這一步，新標籤會 fall through 到 default 的
  `pv-down-vol-down`，等於在 UI 上把剛修掉的缺陷重新引入一次
- 評語措辭同步：量增平盤不再說「但下跌，賣壓較重」，改為「成交活躍卻未形成方向」；
  BFP 的「賣壓沉重」同理

**分數一律未動。** `priceUp` 餵給評分分支的布林值原封不動，`TestFlatCorrectionDoesNotMoveScores`
斷言平盤與下跌在量增時仍拿相同的 VolumeScore。

**帶寬刻意維持恰好為零。** `TestNearFlatSessionsKeepTheirDirection` 守住 −0.26% 仍是「價跌量縮」。

### 三個候選策略都未獲支持

```
量增：FLAT 33.5%  DOWN 35.7%  UP 33.0%   (baseline 34.7%)
量縮：FLAT 31.2%  DOWN 34.5%  UP 33.7%   (baseline 34.7%)
```

FLAT **在兩個半邊都不是介於漲跌之間，而是最差或接近最差的一格**，且低於 baseline
2.5 個百分點（`PV_FLAT_ANY_VOLUME` 32.2% vs 34.7%）。

- **候選 A（FLAT 視為 DOWN，現況）** —— DOWN 在兩邊都優於 FLAT，把 FLAT 當 DOWN 是**高估**它
- **候選 C（FLAT 視為 UP）** —— UP 在量縮時優於 FLAT，同樣是高估
- **候選 B（FLAT 自成中性一格）** —— 資料確實顯示 FLAT 與另外兩者可分，但**方向是更差，不是中性**

## ⚠️ 決定性的混淆：FLAT 選到的是母體，不是事件

| condition | 中位進場價 | 不重複股票 |
|---|---|---|
| PV_BASELINE_ALL_BARS | 46.1 | 1974 |
| PV_FLAT_ANY_VOLUME | **35.6** | 1973 |
| PV_FLAT_VOLUME_EXPANSION | **31.9** | 1576 |

FLAT 訊號的中位股價比 baseline **低 23%**，量增時低 31%。而且**不是集中在少數股票**
（訊號最多的前 8 檔僅佔 1.3%，散佈於 1973 檔）—— 這不是幾檔怪股的雜訊，是**系統性的
母體偏移**。

低價、低波動的股票結構上更容易收在同一個檔位。**「恰好平盤」在很大程度上是在挑選
「便宜且清淡」的股票，而不是在偵測「今天沒有形成方向」這個事件。**

因此若依這份結果調低 FLAT 的分數，實際被扣分的是**低價股**，而不是「無方向」——
那是一個完全沒有人驗證過、也不是原本想問的主張。

## 結論

**NO PRODUCTION MIGRATION.**

- 標籤修正**已上線**，它自己站得住：把 0.00% 說成跌是假陳述，與任何回測結果無關
- **scoring 一律不動**。三個候選都未獲支持，且存在會讓任何調整變成「懲罰低價股」的混淆
- 語意上正確的處置是**候選 B（中性）**，而標籤現在做的正是這件事；分數維持現狀是因為
  資料不支持任何改動，不是因為 B 不對

### 統計信心：NOT ESTABLISHED

bar 級重疊觀察值、未做顯著性檢定、單一約 14 個月區間、倖存者偏誤。條件間差距 2~3
個百分點，在有效樣本數未知的前提下不足以支撐任何 scoring 變更。
