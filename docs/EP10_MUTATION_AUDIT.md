## What the runner checks (scripts/ep10_mutation/main.go)

Before the first mutant it records the SHA-256 of every watched file and runs every distinct test
command once on the unmutated tree, aborting if any fails. For each mutant (one or more exact
replacements in one file) it:

1. requires every anchor to occur exactly once;
2. requires at least one changed line to be code, not blank and not a `//` comment;
3. requires the file's SHA-256 to change;
4. requires `go build ./...` to pass on the mutant (otherwise the row is `INVALID`);
5. runs `go test <pkg> -run ^<Test>$ -count=1`; the row is `KILLED` only when the output contains
   `--- FAIL: <Test> `, i.e. an assertion failure in the intended test;
6. writes the original bytes back and re-checks the SHA-256 against the baseline (a mismatch aborts).

The run's exit status is non-zero if any mutant is a TRUE_SURVIVOR, is INVALID, or was
declared EQUIVALENT/VACUOUS and then killed (MISCLASSIFIED). A declared EQUIVALENT or
VACUOUS row does NOT fail the run: changing production semantics to reach a zero-survivor
table is forbidden, so the honest outcome is classified instead of engineered away.

After the last mutant it re-checks every watched file against its baseline. A deferred restore
rewrites every watched file on a panic; it does not run on `os.Exit`, which is only called before
the first mutation, after the current file has been written back, or after this file is written.

## Classification

Every mutant lands in exactly ONE of four buckets. `SURVIVED` is not a bucket: a mutant that
is not killed is either EQUIVALENT (unreachable branch, premises stated and machine-pinned),
VACUOUS (an observable no-op on the population it touches — a defect in the MUTANT), or a
TRUE_SURVIVOR (a gap in the tests). **TRUE_SURVIVOR and INVALID must both be zero**, and no
production semantics were changed to move any row between buckets.

| Bucket | Meaning |
| --- | --- |
| `KILLED` | the intended test reported an assertion failure on the mutant |
| `EQUIVALENT` | declared in advance; the mutated branch is unreachable, the premises are listed below and at least one is pinned by a named test |
| `VACUOUS` | declared in advance; the mutation is a no-op on the population it touches, so no test could kill it |
| `TRUE_SURVIVOR` | not killed and not declared — a real gap |
